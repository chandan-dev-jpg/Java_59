--it allows programmers to write instruction that a computer can understand and execute.

EX:C,C++,Java,python

characteristics of  java programming language:

Java language has provided two characteristics:

a) Syntax [Rules given by java programming language]
Syntax is the correct structure or format of writing code in a programming language.

b)Sematic [Meaning OR Structure given by java language]
"Semantics is the meaning or behavior of a program statement. It describes what the code does when it is executed."


//Bytecode
"Bytecode is the intermediate code generated by the Java compiler (javac) and stored in a .class file. It is executed by the JVM, making Java platform independent." 

//SourceCode
"Source code is the original human-readable program written by a programmer in a programming language, such as a .java file in Java." 

Source Code (.java)
        ↓
     Compiler (javac)
        ↓
   Bytecode (.class)
        ↓
       JVM
        ↓
      Output

Java Compiler

      "The Java Compiler (javac) is a tool that converts Java source code (.java) into bytecode (.class), which is executed by the JVM." 

JRE 

      "JRE (Java Runtime Environment) is a software package that contains the JVM and Java libraries required to run Java applications."

      Java

"Java is a high-level, object-oriented, platform-independent programming language used to develop secure, robust, and portable applications."
