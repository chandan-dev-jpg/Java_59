Java Compiler

      "The Java Compiler (javac) is a tool that converts Java source code (.java) into bytecode (.class), which is executed by the JVM." 

JDK   == JRE + JDK Development tools

      JDK (Java Development Kit) is a software package used to develop, compile, and run Java applications.
      
      it is Developer version that means by using JDK we can develop & execute our java program.


JRE   == JVM + Class Libraries

      "JRE (Java Runtime Environment) is a software package that contains the JVM and Java libraries required to run Java applications."

      it is client version because by using JRE we can only execute our java program.

JVM   == Class Loader +Runtime

       JVM (Java Virtual Machine) is a virtual machine that executes Java bytecode and allows Java programs to run on any operating system.
       
       The main propose of JVM to load & execute the byte code(.class file).

java pure object Oriented or not
---------------------------------

* No java is not a pure object oriented language because it accepts primary data type.

* A pure object oriented language will directly accept object but not primitive.

Primitive data types are not objects. They store values directly and do not have methods or references. Wrapper classes such as Integer, Double, and Character are objects that represent primitive values.
