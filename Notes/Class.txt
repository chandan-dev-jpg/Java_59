===============================
           CLASS IN JAVA
===============================

Definition:
A class is a blueprint or template for creating objects.

OR

A class is a user-defined data type that contains variables (fields) and methods.

OR 
A class is a logical entity which contains object properties & object behavior.
--------------------------------

Syntax:

class ClassName {

    // Variables (Fields)

    // Methods

}

--------------------------------

Example:

class Student {

    int id;
    String name;

    void display() {
        System.out.println(id + " " + name);
    }
}

--------------------------------

Creating an Object

class Demo {
    public static void main(String[] args) {

        Student s1 = new Student();

        s1.id = 101;
        s1.name = "Chandan";

        s1.display();
    }
}

Output:
101 Chandan

--------------------------------

Components of a Class

• Fields (Variables)
• Methods
• Constructors
• Blocks (Static/Instance)
• Nested Classes (Optional)

--------------------------------

Characteristics of a Class

• User-defined data type.
• Blueprint for creating objects.
• Can contain variables, methods, constructors, and blocks.
• Supports Object-Oriented Programming (OOP).
• A class itself does not occupy memory for instance variables until an object is created.

--------------------------------

Advantages of a Class

• Promotes code reusability.
• Supports encapsulation.
• Makes programs modular.
• Easy to maintain and extend.
• Helps organize related data and methods.

--------------------------------

Difference Between Class and Object

Class                          Object
---------------------------------------------------
Blueprint or template          Instance of a class
Logical entity                 Physical entity
No memory for instance data    Occupies memory
Used to create objects         Created using the new keyword
Example: Student               Example: s1

--------------------------------

Important Points

• A class is declared using the class keyword.
• A class can contain variables, methods, constructors, and blocks.
• Multiple objects can be created from one class.
• Objects are created using the new keyword.
• Java supports only single inheritance for classes.

--------------------------------

Interview Definition

A class is a blueprint or template for creating objects. It is a user-defined data type that groups variables and methods into a single unit.

===============================
        I/O CLASSES IN JAVA
===============================

Definition:
I/O (Input/Output) classes are predefined classes used to read input from and write output to different sources such as the keyboard, files, and streams.

--------------------------------

What is I/O?

Input  → Receiving data (Keyboard, File, Network)
Output → Displaying or writing data (Console, File, Printer)

--------------------------------

Common I/O Classes

1. Scanner
2. BufferedReader
3. Console
4. FileReader
5. FileWriter
6. FileInputStream
7. FileOutputStream
8. BufferedInputStream
9. BufferedOutputStream
10. PrintWriter

--------------------------------

1. Scanner Class

• Used to read input from the keyboard.
• Package: java.util.Scanner

Example:

import java.util.Scanner;

Scanner sc = new Scanner(System.in);

--------------------------------

2. BufferedReader

• Reads character input efficiently.
• Package: java.io

Example:

BufferedReader br =
new BufferedReader(new InputStreamReader(System.in));

--------------------------------

3. Console Class

• Reads data securely from the console.
• Package: java.io

Example:

Console con = System.console();

--------------------------------

4. FileReader

• Reads character data from a file.

Example:

FileReader fr = new FileReader("data.txt");

--------------------------------

5. FileWriter

• Writes character data to a file.

Example:

FileWriter fw = new FileWriter("data.txt");

--------------------------------

6. FileInputStream

• Reads byte data from a file.

Example:

FileInputStream fis =
new FileInputStream("data.txt");

--------------------------------

7. FileOutputStream

• Writes byte data to a file.

Example:

FileOutputStream fos =
new FileOutputStream("data.txt");

--------------------------------

Important Points

• I/O means Input and Output.
• Java provides predefined I/O classes.
• Scanner is the most commonly used class for keyboard input.
• BufferedReader is faster than Scanner for reading text.
• FileReader/FileWriter work with character data.
• FileInputStream/FileOutputStream work with byte data.
• Most I/O classes belong to the java.io package.
• Scanner belongs to the java.util package.

--------------------------------

Difference Between Scanner and BufferedReader

Scanner                    BufferedReader
---------------------------------------------------
java.util package          java.io package
Easy to use                Faster
Parses different data      Reads only text
nextInt(), nextDouble()    readLine()

--------------------------------

Interview Definition

I/O (Input/Output) classes are predefined classes in Java used to read input from various sources and write output to different destinations such as the console, files, and streams.
