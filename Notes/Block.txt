Block
------
-It is self defined statement which se can write inside the method body represent a particular block OR group of statement.

-In Java, a block is a group of zero or more statements enclosed within curly braces {}.

-If we declare any variable inside the block then the scope of that variable will be within the same block only that means we cannot use that variable outside of the block as shown in the program.

-Variables declared inside a block are only accessible within that block.

-By default blocks are executed from top to bottom.

-As we know blocks are executed from top to bottom, if we want to control the execution flow of the block as per our requirement then we should use Control statement.
