=========================================
        TYPE PROMOTION IN JAVA
=========================================

Definition:
Type Promotion is the automatic conversion of smaller data types into a larger data type during an expression or arithmetic operation.

OR

Type Promotion is the process in which Java automatically promotes operands to a larger data type before performing an operation.

-----------------------------------------

Promotion Rules

1. byte, short and char are promoted to int.
2. If one operand is long, the result is long.
3. If one operand is float, the result is float.
4. If one operand is double, the result is double.

Priority:

byte
  ↓
short
  ↓
char
  ↓
int
  ↓
long
  ↓
float
  ↓
double

-----------------------------------------

Example 1

class Demo {
    public static void main(String[] args) {

        byte a = 10;
        byte b = 20;

        int c = a + b;

        System.out.println(c);
    }
}

Output:
30

Reason:
byte + byte → int

-----------------------------------------

Example 2

class Demo {
    public static void main(String[] args) {

        int a = 10;
        long b = 20;

        long c = a + b;

        System.out.println(c);
    }
}

Output:
30

Reason:
int + long → long

-----------------------------------------

Example 3

class Demo {
    public static void main(String[] args) {

        int a = 10;
        double b = 20.5;

        double c = a + b;

        System.out.println(c);
    }
}

Output:
30.5

Reason:
int + double → double

-----------------------------------------

Example 4

class Demo {
    public static void main(String[] args) {

        char ch = 'A';

        int result = ch + 1;

        System.out.println(result);
    }
}

Output:
66

Reason:
'A' = 65
65 + 1 = 66

-----------------------------------------

Important Points

• Performed automatically by Java.
• Happens during arithmetic expressions.
• byte, short and char are promoted to int.
• The result is promoted to the largest data type involved.
• No casting is required.

-----------------------------------------

Difference Between Type Promotion and Type Casting

Type Promotion              Type Casting
---------------------------------------------------
Automatic                   Automatic or Manual
Occurs in expressions       Converts one type to another
No casting operator         May require casting operator
Used in arithmetic          Used for assignments/conversions

-----------------------------------------

Interview Definition

Type Promotion is the automatic conversion of smaller data types into a larger data type during arithmetic operations. Java promotes operands to the largest compatible data type before performing the operation.
