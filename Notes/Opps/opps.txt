Object Oriented Programming (OOPs):
-----------------------------------

What is an Object ?
-------------------

*An object is a physical entity which exist in the real world.

Ex:
Marker,Keyword,Car,Fan,Bike,any real world physical entity.

*An object is having 3 Characteristics.

1) Identification of the object (name of the object).

2)State of an object (Properties / Attributes / Non static fields)

3)Functionality of object (Behavior of the object Non static methods)

* if we want to create an object in java by using new keyword then class name is compulsory.

Ex:public class Student{

}

Student raj=new Student();

Student -->Class Name
raj     -->Reference Variable
new     --->keyword for dynamic memory allocation.
Student  -->constructor

What is OOP:
-----------

*Object Oriented Programming is a technique through which we can design and develop the java programs using class and object.

*In OOP we always concentrate on the objects rather then function.

*Writing program on real life objects is know as Object Oriented Programming.

* The person who writes the program know as Object Oriented Programmer.

Advantages of OPP :
--------------------

1.Modularity (Dividing the bigger tsk into smaller task )
2.Reusability (We can reuse the component (classes and methods) so many times)
3.Flexibility (Easy to maintain (By using interface))

Feature of OPP :
----------------
a.Class
b.Object
c.Abstraction
d.encapsulation
e.inheritance
f.Polymorphism

What is a class ?
----------------
*A class is a logical entity which contains Object properties and Object behavior

EX:

public class Student{
    Student Properties(Non static fields)
                    +
    Student Behavior (Non static methods)                
}
