*A static block is a special block which is automaticaly executed at the time of loading the .class file into JVM memory.

EX:
public class Test
{
   static {
//static Block
    }
}

*In java A class file  will be loaded only once so ,unlike non-static block, static block will be executed only one time.
*In java, A class is not loaded automatically ,Actually it is loaded based on the user requset.
*A static block will be always executed before main method OR any static method as well as we cannot write static block inside the main method.
*The main purpose of static block to initialize the static fields of the class that is the reason it is also known as static initialize.
*If we have multiple static blocks then all the static block will be executed from top to buttom.[According to the oredr]S

{static method is having low priority then static block}
