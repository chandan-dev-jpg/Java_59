Instance Block OR Static Block 
-------------------------------
* It is very speacial block in java which wiil be automatically executed at the time of creating the object.

Ex:

class Test
{
    {
        IO.println("Non Static Block");
        //Inside the class but outside of the method OR constructor OR Block.
    }
}

*Java compiler will automatically placed the non static block in the 2nd line of constructor, if and only if, first line constains super()
