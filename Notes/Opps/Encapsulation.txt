
┌──────────────────────────────────────────────────────────────────────────────┐
│                        ENCAPSULATION IN JAVA                                 │
├──────────────────────────────────────────────────────────────────────────────┤
│ Definition:                                                                  │
│ Encapsulation is the process of wrapping data (variables) and methods        │
│ (functions) into a single unit (class) and restricting direct access to      │
│ the data using private access.                                               │
├──────────────────────────────────────────────────────────────────────────────┤
│ Why Use Encapsulation?                                                       │
│ ✔ Data Hiding                                                                │
│ ✔ Data Security                                                              │
│ ✔ Data Validation                                                            │
│ ✔ Better Code Maintenance                                                    │
│ ✔ Improves Reusability                                                       │
│ ✔ Increases Flexibility                                                      │
├──────────────────────────────────────────────────────────────────────────────┤
│ How to Achieve Encapsulation?                                                │
│ 1. Declare variables as private.                                             │
│ 2. Provide public getter() methods to read data.                             │
│ 3. Provide public setter() methods to update data.                           │
├──────────────────────────────────────────────────────────────────────────────┤
│ Example:                                                                     │
│ class Student {                                                              │
│     private String name;                                                     │
│                                                                              │
│     public void setName(String name) {                                       │
│         this.name = name;                                                    │
│     }                                                                        │
│                                                                              │
│     public String getName() {                                                │
│         return name;                                                         │
│     }                                                                        │
│ }                                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│ Advantages:                                                                  │
│ • Prevents unauthorized access                                               │
│ • Controls how data is modified                                              │
│ • Makes code secure and organized                                            │
│ • Supports object-oriented programming principles                            │
├──────────────────────────────────────────────────────────────────────────────┤
│ Real-Life Example:                                                           │
│ ATM → You cannot access the bank balance directly.                           │
│ You use ATM operations (Deposit, Withdraw, Balance Enquiry).                 │
│ Similarly, in Java, private data is accessed through getter and setter.      │
└──────────────────────────────────────────────────────────────────────────────┘
