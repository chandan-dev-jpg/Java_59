Non static OR Instance Variable
---------------------------------
* It is a variable which we are defining inside the class.
*If a non static field (not declared with static modifier) is declared inside the class but outside of the method then it is called non static field.

EX:

public class Student 
{
    int roll;
    String name;
}

*The non static field we should use to represent object properties.
*The life of the non static filed will only start when we create an object that means without an object we can not thick about non static field.


┌──────────────────────────────────────────────────────────────────────────────┐
│                  ROLE OF NON-STATIC FIELD IN JAVA                            │
├──────────────────────────────────────────────────────────────────────────────┤
│ Definition                                                                   │
│ A non-static field (instance variable) stores the data of an individual      │
│ object. Each object has its own separate copy of the field.                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ Role of Non-Static Field                                                     │
│ ✓ Stores object-specific (instance) data.                                    │
│ ✓ Each object gets its own copy of the field.                                │
│ ✓ Values can be different for different objects.                             │
│ ✓ Memory is allocated when an object is created using the new keyword.        │
│ ✓ Stored in Heap Memory as part of the object.                               │
├──────────────────────────────────────────────────────────────────────────────┤
│ Example                                                                      │
│ class Student {                                                              │
│     String name;                                                             │
│     int age;                                                                 │
│ }                                                                            │
│                                                                              │
│ Student s1 = new Student();                                                  │
│ s1.name = "Rahul";                                                           │
│                                                                              │
│ Student s2 = new Student();                                                  │
│ s2.name = "Amit";                                                            │
│                                                                              │
│ s1.name → Rahul                                                              │
│ s2.name → Amit                                                               │
│ (Each object has its own copy.)                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│ Memory                                                                       │
│ Stack                     Heap                                               │
│ s1 ───────────────► Student Object { name="Rahul", age=0 }                   │
│ s2 ───────────────► Student Object { name="Amit",  age=0 }                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ Interview Answer                                                             │
│ A non-static field is used to store object-specific data. Every object has   │
│ its own separate copy of the field, so changing one object's value does not  │
│ affect another object's value.                                               │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│                     ROLE OF STATIC FIELD IN JAVA                             │
├──────────────────────────────────────────────────────────────────────────────┤
│ Definition                                                                   │
│ A static field (class variable) stores data that is common to all objects    │
│ of a class. Only one copy of the static field exists, and it is shared by    │
│ every object.                                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│ Role of Static Field                                                         │
│ ✓ Stores class-level (shared) data.                                          │
│ ✓ Only one copy exists for the entire class.                                 │
│ ✓ Shared by all objects of the class.                                        │
│ ✓ Memory is allocated when the class is loaded by the JVM.                   │
│ ✓ Stored in the Method Area (Class Area).                                    │
│ ✓ Can be accessed using the class name without creating an object.           │
├──────────────────────────────────────────────────────────────────────────────┤
│ Example                                                                      │
│ class Student {                                                              │
│     static String college = "ABC College";                                   │
│ }                                                                            │
│                                                                              │
│ Student s1 = new Student();                                                  │
│ Student s2 = new Student();                                                  │
│                                                                              │
│ System.out.println(Student.college);                                         │
│ System.out.println(s1.college);                                              │
│ System.out.println(s2.college);                                              │
│                                                                              │
│ Output:                                                                      │
│ ABC College                                                                  │
│ ABC College                                                                  │
│ ABC College                                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ Memory                                                                       │
│ Method Area (Class Area)                                                     │
│ ┌──────────────────────────────┐                                             │
│ │ Student.college = "ABC College" │  ← One shared copy                       │
│ └──────────────────────────────┘                                             │
│            ▲                  ▲                                              │
│            │                  │                                              │
│          s1 Object         s2 Object                                         │
├──────────────────────────────────────────────────────────────────────────────┤
│ Interview Answer                                                             │
│ A static field is used to store data that is common to all objects of a      │
│ class. It has only one shared copy, is created when the class is loaded,     │
│ and can be accessed using the class name.                                    │
└──────────────────────────────────────────────────────────────────────────────┘
*Main Propose of static field is save the memory.

*Whenever we create an object in java then a single copy of static field will be created and the same single copy will be shareable by all the objects as shown in the program & diagram.
