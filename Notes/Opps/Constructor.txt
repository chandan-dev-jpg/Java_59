*If the name of the class and name of the method both are exactly same and it should contain any return type then it is called constructor.

EX:

public class Student{
    public void Student() //Method [due to void return type it is a method]
    {

    }

    public Student()    //Constructor [There is no return type]
    {

    }
}


*Whenever we write a class in java (ELC and BLC ) and if we don't write any type of constructor then automatically java compiler will add one default no argument constructor (constructor without parameter) in the class.
(we can not think about a java class without constructor)

*Every java must have one constructor either implicity added by java compiler OR explicity written by developer.

*Every time we will create an object in java by using new keyword thaen at least one constructor must be invoked.



Default no argument constructor :
----------------------------------
*It is automatically added by java compiler to reach and every class ,if developer has not providede any type of constructor in the class.


Why is it added?
✅ To allow object creation using new ClassName().
✅ To initialize instance variables with their default values (0, false, null, etc.).
✅ To call the parent class constructor (super()).
✅ To ensure every object is properly initialized.

┌──────────────────────────────────────────────────────────────────────────────┐
│                      CONSTRUCTOR IN JAVA (ONE BOX NOTES)                     │
├──────────────────────────────────────────────────────────────────────────────┤
│ Definition                                                                   │
│ A constructor is a special method that is automatically called when an       │
│ object is created. It is used to initialize the object's data (fields).      │
├──────────────────────────────────────────────────────────────────────────────┤
│ Syntax                                                                       │
│ class Student {                                                              │
│     Student() {                                                              │
│         // Constructor                                                       │
│     }                                                                        │
│ }                                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│ Rules                                                                        │
│ ✓ Constructor name must be the same as the class name.                       │
│ ✓ Constructor has NO return type (not even void).                            │
│ ✓ Constructor is called automatically using the new keyword.                 │
│ ✓ A class can have multiple constructors (Constructor Overloading).          │
│ ✓ Constructors can have access modifiers (public, private, etc.).            │
│ ✓ Constructors cannot be static, final, or abstract.                         │
│ ✓ Constructors are not inherited.                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│ Types of Constructors                                                        │
│ 1. Default Constructor (Compiler Provided)                                   │
│    - Created automatically if no constructor is written.                     │
│                                                                              │
│ 2. No-Argument Constructor (User Defined)                                    │
│    - Written by the programmer without parameters.                           │
│                                                                              │
│ 3. Parameterized Constructor                                                 │
│    - Accepts parameters to initialize object values.                         │
├──────────────────────────────────────────────────────────────────────────────┤
│ Constructor vs Method                                                        │
│ Constructor                     | Method                                     │
│ ------------------------------- | ------------------------------------------ │
│ Same name as class              | Any valid name                             │
│ No return type                  | Must have a return type or void            │
│ Called automatically            | Called explicitly                          │
│ Initializes object              | Performs specific tasks                    │
├──────────────────────────────────────────────────────────────────────────────┤

Types of Constructor in java :
-----------------------------

* in java we have two types of constructor.

1.Implicity OR Compiler added constructor
2.Explicit OR User-defined Constructor.

Implicity OR Compiler added constructor:
-----------------------------------------------

*Whenever we write class in java and if we don't write any type of constructor ,Automatically java compiler will add default no argument constructor.
*It will help to create the object without writing user-defined constructor.

Explicity OR User defined constructor
-------------------------------------
*if a constructor is written by user to the class then it is called Explicit OR User Defined constructor.
*A user can write two types of explicit constructor.

1.No argument OR Zero Argument OR Non-Parameterized OR parameter less constructor
2.Parameterized Constructor.

No Argument Constructor
-----------------------
If a constructor is written by user without any parameter then it is called No Argument Constructor.
it is used to provide the default value for the non static fields.

Actually Internally it will copy the default values provided by new keyword.

Parameterized Constructor
--------------------------
If we pass on or more parameters to the constructor then it is called Parameterized constructor.
it is mainly used to innitilized the non static fields with parameters variable using user values.
