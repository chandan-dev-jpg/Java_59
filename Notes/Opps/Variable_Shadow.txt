variable Shadow 
---------------

*In java class level fields (static field OR Non static field)
name can be same with method level variables (Parameter OR Local)name.

*IF class level fields and method level variables are having exactly same name then method level variable will hide class level fields inside the method OR constructor OR block body,this concept known as variable shadow.

This keyword
-------------
*This Keyword Refers to the current object .

+--------------------------------------------------------------------------------------+
|                             THIS KEYWORD IN JAVA                                     |
+--------------------------------------------------------------------------------------+
| Definition:                                                                          |
| 'this' is a reference keyword that refers to the current object of a class.          |
| It is used to access the current object's variables, methods, and constructors.      |
|                                                                                      |
| Uses of 'this':                                                                      |
| • Refers to the current object's instance variables.                                 |
| • Resolves naming conflicts between local variables and instance variables.           |
| • Calls the current class methods.                                                   |
| • Invokes another constructor of the same class using this().                        |
| • Passes the current object as an argument to a method or constructor.               |
| • Returns the current object from a method.                                          |
|                                                                                      |
| Syntax:                                                                              |
| this.variable;                                                                       |
| this.method();                                                                       |
| this();   // Must be the first statement inside a constructor                        |
|                                                                                      |
| Example:                                                                             |
| class Student {                                                                      |
|     int id;                                                                          |
|     Student(int id) {                                                                |
|         this.id = id;                                                                |
|     }                                                                                |
| }                                                                                    |
+--------------------------------------------------------------------------------------+
