*In java int between the classes we have 2 types of relation.

1)IS-A Relation [We can achieve through Inheritance]

An IS-A relationship means one class is a specialized form of another class. It is achieved using the extends keyword (or implements for interfaces).


class Parent {
}

class Child extends Parent {
}


2)HAS-A Relation [We can achieve through Association]

HAS-A relationship means one class contains an object of another class. It is used for code reuse instead of inheritance.

class Engine {
}

class Car {
    Engine engine = new Engine();   // HAS-A relationship
}
