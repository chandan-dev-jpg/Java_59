Keywords
--------
* A keyword is a predefined word whose meaning is alerady defined by the compiler.
-We have 67+ keywords in java
| Keyword        | Use                              |
| -------------- | -------------------------------- |
| `class`        | Declare a class                  |
| `public`       | Accessible from anywhere         |
| `private`      | Accessible only within the class |
| `static`       | Belongs to the class             |
| `final`        | Cannot be changed/inherited      |
| `if`           | Conditional statement            |
| `for`          | Loop                             |
| `while`        | Loop                             |
| `return`       | Returns a value from a method    |
| `new`          | Creates an object                |
| `this`         | Refers to the current object     |
| `super`        | Refers to the parent class       |
| `extends`      | Inheritance                      |
| `implements`   | Implements an interface          |
| `try`, `catch` | Exception handling               |
| `void`         | No return value                  |

Definition:
Keywords are reserved words that have predefined meanings in Java. They cannot be used as identifiers (variable names, method names, class names, etc.).

Example

--------------------------------

Important Points

• Keywords are reserved words.
• They have predefined meanings.
• They cannot be used as identifiers.
• Java keywords are case-sensitive.
• All keywords are written in lowercase.

--------------------------------

Difference Between Keyword and Identifier

Keyword                     Identifier
---------------------------------------------------
Reserved word               User-defined name
Predefined meaning          No predefined meaning
Cannot be used as a name    Used to name variables, methods, classes, etc.
Examples: int, class, if    Examples: age, Student, display

--------------------------------

Interview Definition

A keyword is a reserved word in Java that has a predefined meaning and cannot be used as an identifier.
