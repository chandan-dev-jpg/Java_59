Control Statements in Java

Control statements control the flow of execution of a Java program. They decide which statements execute, how many times they execute, or whether execution jumps to another part of the program.

There are three types of control statements:

1. Selection (Decision-Making) Statements

Used to choose one block of code based on a condition.

if
if-else
else-if ladder
nested if
switch

2.Iteration (Looping) Statements

Used to execute a block of code repeatedly.

for
while
do-while
Enhanced for (for-each)

3.Jump (Branching) Statements

Used to transfer control from one part of the program to another.

break – Terminates a loop or switch.
continue – Skips the current iteration and moves to the next.
return – Exits a method and optionally returns a value.
yield  -


Decision-Making (Selection) Statements

1.if Statement

-Used to execute a block of code only if the condition is true.
-it is used to boolean expression.
-The expression must return boolean type.
-It allows us to execute a block of code only when a given condition is true.
-If the condition false then control skips the if block and moves to next statement.

2.if-else Statement

-the if else statement it used when one action must be performed if the codition is true and a different action must be performed if the condition false.
-Used to choose one of two blocks based on a condition.

3.else-if Ladder

Used to check multiple conditions.

4.nested if

An if statement inside another if statement.

5.switch

-it is a selective statement in java so we can select one case among the available cases.

The switch statement checks the value of an expression and executes the matching case block. If no case matches, the default block is executed.

-We can write default so if any statement is not matching then default will be executed but it is optional.


Old switch uses : and usually requires break to prevent fall-through. New switch uses ->, does not require break, prevents fall-through automatically, and can be used as an expression to return a value.

-If we have multiple statement then { } are compulsory.

points
------
a.We can not accept duplicate case value.
b.the label of case must be constant OR literals.
c.The default case is optional and executes if no case matches in the expression.

Switch expression (14v)
-----------------------
A switch expression evaluates an expression, executes the matching case, and returns a value.

Rules
-----
a.While writing switch body ; (semicolon is compulsory at the end).
b.Here default -> is compulsory (if no case match then default will be return)

yield
--------
The yield keyword is used in a switch expression to return a value from a case block when that case contains multiple statements.



Lopping Statement
-----------------
Looping statements are used to execute a block of code repeatedly until a specified condition becomes false.

===============================
      JAVA LOOPING STATEMENTS
===============================

1. FOR LOOP
--------------------------------
Definition:
The for loop is used to execute a block of code repeatedly when the number of iterations is known.

Syntax:
for(initialization; condition; update) {
    // statements
}

Important Points:
• Entry-controlled loop.
• Condition is checked before execution.
• Initialization, condition, and update are written in one place.
• Best when the number of iterations is known.
• May execute zero or more times.

Example:
for(int i = 1; i <= 5; i++) {
    System.out.println(i);
}

--------------------------------

2. WHILE LOOP
--------------------------------
Definition:
The while loop executes a block of code repeatedly as long as the condition is true.

Syntax:
while(condition) {
    // statements
}

Important Points:
• Entry-controlled loop.
• Condition is checked before execution.
• Best when the number of iterations is unknown.
• May execute zero or more times.

Example:
int i = 1;
while(i <= 5) {
    System.out.println(i);
    i++;
}

--------------------------------

3. DO-WHILE LOOP
--------------------------------
Definition:
The do-while loop executes the loop body first and then checks the condition.

Syntax:
do {
    // statements
} while(condition);

Important Points:
• Exit-controlled loop.
• Condition is checked after execution.
• Executes at least one time.
• Useful when one execution is mandatory.

Example:
int i = 1;
do {
    System.out.println(i);
    i++;
} while(i <= 5);

--------------------------------

4. ENHANCED FOR LOOP (FOR-EACH)(1.5v)
--------------------------------
Definition:
The enhanced for loop is used to traverse arrays and collections one element at a time.

-it is used to iterate OR retrieve the values one by one from the collections OR Array.
-Automatically java compiler will convert the for-each into ordinary for loop.
Syntax:
for(dataType variable : array) {
    // statements
}

Important Points:
• Introduced in Java 5.
• Used for arrays and collections.
• No index variable is required.
• Simple and easy to read.
• Cannot directly modify array elements using the loop variable.

Example:
int[] arr = {10, 20, 30};

for(int num : arr) {
    System.out.println(num);
}

--------------------------------

Difference

for        → Known number of iterations.
while      → Unknown number of iterations.
do-while   → Executes at least once.
for-each   → Used for arrays and collections.
