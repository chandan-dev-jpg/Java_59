Type Casting 
-------------
* it is a technique to convert one data type to another data type.

*In java, We have 2 types of type casting :

1.Implicit OR Automatic OR WIDENING Type casting
2.Explicit OR Manual OR Narrowing Type Casing


1.Implicit type Casting
------------------------

Converting a smaller data type into a larger data type automatically by the compiler.

EX:
byte b=12;
short s=b;

2.Explicit type Casting
-------------------------

* If we try to assign a bigger data type value into smaller data type then it is called Explicit type.
* in Explicit or Manual or Narrowing there is a loss of data.

EX:
short s=127;
byte b=(byte)s;

===============================
        TYPE CASTING IN JAVA
===============================

Definition:
Type Casting is the process of converting one data type into another data type.

--------------------------------

Types of Type Casting

1. Widening Type Casting (Implicit)
2. Narrowing Type Casting (Explicit)

--------------------------------

1. WIDENING TYPE CASTING
(Automatic / Implicit)

Definition:
Widening is the automatic conversion of a smaller data type into a larger data type.

Conversion Order:

byte → short → int → long → float → double
             ↘
              char → int → long → float → double

Example:
int a = 10;
double b = a;

System.out.println(b);

Output:
10.0

Important Points:
• Performed automatically by Java.
• No data loss.
• No type casting operator is required.
• Also called Implicit Type Casting.

--------------------------------

2. NARROWING TYPE CASTING
(Manual / Explicit)

Definition:
Narrowing is the manual conversion of a larger data type into a smaller data type.

Example:
double a = 10.5;
int b = (int)a;

System.out.println(b);

Output:
10

Important Points:
• Performed manually by the programmer.
• Type casting operator is required.
• Data loss may occur.
• Decimal part is truncated.
• Also called Explicit Type Casting.

--------------------------------

Type Casting Examples

Example 1:
byte a = 10;
int b = a;

Output:
10

Example 2:
double x = 25.75;
int y = (int)x;

Output:
25

--------------------------------

Difference Between Widening and Narrowing

Widening                  Narrowing
-------------------------------------------------
Automatic                 Manual
Implicit                  Explicit
No casting operator       Casting operator required
No data loss              Data loss may occur
Small → Large             Large → Small

--------------------------------

Interview Definition

Type Casting is the process of converting one data type into another data type.

• Widening (Implicit): Converts a smaller data type into a larger data type automatically.

• Narrowing (Explicit): Converts a larger data type into a smaller data type manually using the type casting operator.

=========================================
     WIDENING & NARROWING IN JAVA
=========================================

Definition:
Widening and Narrowing are the two types of type casting in Java.

-----------------------------------------

1. WIDENING (Implicit Type Casting)

Definition:
Widening is the automatic conversion of a smaller data type into a larger data type.

Conversion Order:

byte → short → int → long → float → double
             ↘
              char → int → long → float → double

Example:

class Demo {
    public static void main(String[] args) {

        int a = 100;

        double b = a;

        System.out.println(b);
    }
}

Output:
100.0

Important Points

• Automatic conversion.
• No type casting operator is required.
• No data loss.
• Also called Implicit Type Casting.
• Small data type → Large data type.

-----------------------------------------

2. NARROWING (Explicit Type Casting)

Definition:
Narrowing is the manual conversion of a larger data type into a smaller data type.

Example:

class Demo {
    public static void main(String[] args) {

        double a = 10.75;

        int b = (int)a;

        System.out.println(b);
    }
}

Output:
10

Important Points

• Manual conversion.
• Type casting operator is required.
• Data loss may occur.
• Decimal part is removed.
• Also called Explicit Type Casting.
• Large data type → Small data type.

-----------------------------------------

Difference Between Widening and Narrowing

Widening                     Narrowing
---------------------------------------------------
Automatic                    Manual
Implicit                     Explicit
No casting operator          Casting operator required
No data loss                 Data loss may occur
Small → Large                Large → Small

-----------------------------------------

Interview Definition

Widening:
Widening is the automatic conversion of a smaller data type into a larger data type without data loss.

Narrowing:
Narrowing is the manual conversion of a larger data type into a smaller data type using the type casting operator. It may cause data loss.
