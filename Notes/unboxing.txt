=========================================
          UNBOXING IN JAVA
=========================================

Definition:
Unboxing is the automatic conversion of a wrapper class object into its corresponding primitive data type.

OR

Unboxing is the process in which Java automatically converts a wrapper object into a primitive value.

-----------------------------------------

Wrapper → Primitive

Byte      → byte
Short     → short
Integer   → int
Long      → long
Float     → float
Double    → double
Character → char
Boolean   → boolean

-----------------------------------------

Syntax

Integer obj = 10;
int a = obj;      // Unboxing

-----------------------------------------

Example 1

class Demo {
    public static void main(String[] args) {

        Integer obj = 100;

        int a = obj;

        System.out.println(obj);
        System.out.println(a);
    }
}

Output:
100
100

-----------------------------------------

Example 2

class Demo {
    public static void main(String[] args) {

        Double obj = 10.5;

        double d = obj;

        System.out.println(d);
    }
}

Output:
10.5

-----------------------------------------

How It Works

Integer obj = 10;

int a = obj.intValue();

(Java performs this conversion automatically.)

-----------------------------------------

Why Unboxing?

• Converts wrapper objects into primitive values.
• Simplifies coding.
• Eliminates manual conversion.
• Useful when performing arithmetic operations.

-----------------------------------------

Important Points

• Introduced in Java 5.
• Automatic conversion.
• Wrapper Object → Primitive.
• No explicit conversion is required.
• Opposite process is called Autoboxing.

-----------------------------------------

Difference Between Autoboxing and Unboxing

Autoboxing                 Unboxing
---------------------------------------------------
Primitive → Wrapper        Wrapper → Primitive
Automatic                  Automatic
int → Integer              Integer → int
double → Double            Double → double

-----------------------------------------

Interview Definition

Unboxing is the automatic conversion of a wrapper class object into its corresponding primitive data type. It was introduced in Java 5 to simplify programming.
