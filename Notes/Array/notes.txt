*An array is a container object which is used to hold fixed number of values in an ordered collection.
*An array is a reference data type, whenever we create array then array is going to store in the heap memory because array is an object.
*By using array we can hold multiple values of same type i.e homeogenous types of element.
*in java we can create array of primitive type as well as reference type.

=========================
      JAVA ARRAY
=========================

1. What is an Array?
--------------------
An array is a collection of elements of the same data type stored in contiguous memory locations.

Example:
int[] arr = {10, 20, 30, 40, 50};

--------------------
2. Why use Array?
--------------------
✔ Store multiple values in one variable
✔ Faster access using index
✔ Easy to traverse using loops

--------------------
3. Array Declaration
--------------------
int[] arr;
or
int arr[];

--------------------
4. Array Creation
--------------------
arr = new int[5];

--------------------
5. Declaration + Creation
--------------------
int[] arr = new int[5];

--------------------
6. Array Initialization
--------------------
int[] arr = {10,20,30,40,50};

or

int[] arr = new int[]{10,20,30};

--------------------
7. Array Index
--------------------
Index starts from 0.

arr[0]
arr[1]
arr[2]
...

Last Index = length - 1

--------------------
8. Access Elements
--------------------
System.out.println(arr[0]);

--------------------
9. Update Elements
--------------------
arr[1] = 100;

--------------------
10. Array Length
--------------------
arr.length

Example:
System.out.println(arr.length);

--------------------
11. Traversing Array
--------------------

Using for loop

for(int i=0;i<arr.length;i++){
    System.out.println(arr[i]);
}

Using enhanced for loop

for(int x : arr){
    System.out.println(x);
}

--------------------
23. Advantages
--------------------
✔ Fast random access
✔ Less memory overhead
✔ Easy iteration
✔ Simple syntax

--------------------
24. Disadvantages
--------------------
✘ Fixed size
✘ Same data type only
✘ Insertion/Deletion is costly

--------------------
25. Important Interview Points
--------------------
✔ Array index starts from 0.
✔ Arrays are objects in Java.
✔ Size cannot be changed after creation.
✔ Stores homogeneous data.
✔ length is a property (arr.length).
✔ Arrays implement Cloneable and Serializable.
✔ ArrayIndexOutOfBoundsException occurs for invalid indexes.
✔ Negative indexes are not allowed.
✔ Multidimensional arrays are arrays of arrays.

Time Complexity
=========================

Access by Index      O(1)
Traversal            O(n)
Linear Search        O(n)
Binary Search        O(log n) (sorted array)
Sorting              O(n log n)
Insertion            O(n)
Deletion             O(n)

=========================
Example
=========================

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {

        int[] arr = {50, 20, 40, 10, 30};

        Arrays.sort(arr);

        System.out.println(Arrays.toString(arr));

        for(int x : arr){
            System.out.print(x + " ");
        }
    }
}

*In java Basically there are two types of arrays.

1.Single OR One Dimensional Arrays.

A One-Dimensional Array is a linear collection of elements of the same data type, stored in contiguous memory locations. It uses only one index to access elements.

2.2D OR Multidimensional Array.

A Two-Dimensional Array is an array of arrays. It stores data in rows and columns, like a table or matrix.
