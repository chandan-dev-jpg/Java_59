Identifier
-------------

* An identifier in java is a unique name assigned by a developer to programming elements like variables,methods,classes,interfaces and packages to identify them during program execution.

Rules for defining an identifier:
-----------------------------------

1.Can consist of upperCase(A-Z), lowercase(a-z), digits(0-9), $ sign, and underscore(__)
2.Begins with letter , $ , and __
3.It is case sensitive
4.Cannot be a keyword
5.No limitation of length





===============================
        IDENTIFIER IN JAVA
===============================

Definition:
An identifier is the name given to a class, method, variable, interface, package, or object in Java.

OR

An identifier is a user-defined name used to identify program elements.

--------------------------------

Examples:

int age = 20;          // age is an identifier

class Student { }      // Student is an identifier

void display() { }     // display is an identifier

--------------------------------

Rules for Identifiers

• Must start with a letter (A-Z, a-z), '_' (underscore), or '$' (dollar sign).
• Cannot start with a digit (0-9).
• Cannot use Java keywords.
• Identifiers are case-sensitive.
• Cannot contain spaces.
• Can contain letters, digits, '_' and '$'.

--------------------------------

Valid Identifiers

student
studentName
_age
$salary
number123

--------------------------------

Invalid Identifiers

123name      ❌ Starts with a digit
student name ❌ Contains space
class        ❌ Java keyword
total-marks  ❌ Contains '-'

--------------------------------

Naming Conventions

Class Name      → Student, Employee
Method Name     → display(), calculateSum()
Variable Name   → age, salary
Constant Name   → MAX_VALUE, PI

--------------------------------

Important Points

• Identifiers are user-defined names.
• Java keywords cannot be used as identifiers.
• Java is case-sensitive.
• Use meaningful names.
• Follow camelCase for variables and methods.
• Follow PascalCase for class names.
• Use UPPER_CASE for constants.

--------------------------------

Interview Definition

An identifier is a user-defined name used to identify classes, methods, variables, interfaces, packages, and other program elements in Java.
