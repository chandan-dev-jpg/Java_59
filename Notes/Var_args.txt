=========================================
          VAR-ARGS IN JAVA
=========================================

Definition:
Var-args (Variable Arguments) allow a method to accept a variable number of arguments.

OR

Var-args enable a method to receive zero or more arguments of the same data type.

-----------------------------------------

Syntax:

returnType methodName(dataType... variableName) {
    // statements
}

Example:

static void show(int... a) {
    for (int i : a) {
        System.out.println(i);
    }
}

-----------------------------------------

Example 1

class Demo {

    static void add(int... n) {
        int sum = 0;

        for (int i : n) {
            sum += i;
        }

        System.out.println(sum);
    }

    public static void main(String[] args) {
        add();
        add(10);
        add(10, 20);
        add(10, 20, 30);
    }
}

Output:
0
10
30
60

-----------------------------------------

Example 2

class Demo {

    static void display(String... names) {
        for (String s : names) {
            System.out.println(s);
        }
    }

    public static void main(String[] args) {
        display("Ram");
        display("Ram", "Shyam", "Mohan");
    }
}

Output:
Ram
Ram
Shyam
Mohan

-----------------------------------------

Rules of Var-Args

✓ Only one var-args parameter is allowed in a method.
✓ Var-args must be the last parameter.
✓ A method can have normal parameters before var-args.
✓ Var-args can accept zero or more arguments.
✓ Internally, var-args are treated as an array.

Example:

static void show(int x, String... s) {
    // Valid
}

-----------------------------------------

Invalid Example

static void show(String... s, int x) {
}

Reason:
Var-args must always be the last parameter.

-----------------------------------------

Method Overloading with Var-Args

class Demo {

    static void show(int a) {
        System.out.println("int");
    }

    static void show(int... a) {
        System.out.println("var-args");
    }

    public static void main(String[] args) {
        show(10);
        show(10, 20);
    }
}

Output:
int
var-args

-----------------------------------------

Important Points

• Introduced in Java 5.
• Accepts a variable number of arguments.
• Declared using (...) syntax.
• Must be the last parameter.
• Only one var-args parameter is allowed.
• Internally stored as an array.
• Supports method overloading.

-----------------------------------------

Advantages

• Reduces the number of overloaded methods.
• Makes code flexible.
• Improves readability.
• Easy to pass multiple values.

-----------------------------------------

Interview Definition

Var-args (Variable Arguments) allow a method to accept a variable number of arguments of the same type. They are declared using three dots (...) and are internally treated as an array.

=========================================

*It was introduced from JDK 1.5v.
*Var args is known as Variable Argument.
*it is represented by exactly 3dots(...).
*By using va args we can accept 0 to n number of arguments either of same type OR even different type.
*Actually,Internally it is an array.
*Var args we can use only for method OR constructor parameter.
*Var Args must be only one and last parameter for constructor OR method.
*Var Args can accept both array variable ([]arr) as well as direct values (10,20,30).
