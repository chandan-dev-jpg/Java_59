=========================================
         AUTOBOXING IN JAVA
=========================================

Definition:
Autoboxing is the automatic conversion of a primitive data type into its corresponding wrapper class object.

OR

Autoboxing is the process in which Java automatically converts a primitive value into a wrapper object.

-----------------------------------------

Primitive → Wrapper

byte      → Byte
short     → Short
int       → Integer
long      → Long
float     → Float
double    → Double
char      → Character
boolean   → Boolean

-----------------------------------------

Syntax

int a = 10;
Integer obj = a;      // Autoboxing

-----------------------------------------

Example 1

class Demo {
    public static void main(String[] args) {

        int a = 100;

        Integer obj = a;

        System.out.println(a);
        System.out.println(obj);
    }
}

Output:
100
100

-----------------------------------------

Example 2

class Demo {
    public static void main(String[] args) {

        double d = 10.5;
        Double obj = d;

        System.out.println(obj);
    }
}

Output:
10.5

-----------------------------------------

How It Works

int a = 10;

Integer obj = Integer.valueOf(a);

(Java performs this conversion automatically.)

-----------------------------------------

Why Autoboxing?

• Converts primitive values into objects.
• Required when using Collections (ArrayList, HashMap, etc.).
• Simplifies coding.
• Eliminates manual conversion.

-----------------------------------------

Important Points

• Introduced in Java 5.
• Automatic conversion.
• Primitive → Wrapper Object.
• No explicit conversion is required.
• Opposite process is called Unboxing.

-----------------------------------------

Difference Between Autoboxing and Unboxing

Autoboxing                 Unboxing
---------------------------------------------------
Primitive → Wrapper        Wrapper → Primitive
Automatic                  Automatic
int → Integer              Integer → int

-----------------------------------------

Interview Definition

Autoboxing is the automatic conversion of a primitive data type into its corresponding wrapper class object. It was introduced in Java 5 to simplify programming.
