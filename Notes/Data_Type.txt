A data type in Java defines the type of value a variable can store, such as integer, decimal, character, or boolean.

--Size (How Much Memory it Occupies in RAM).

--Range (What values it can hold).

Kinds of Data Types in Java:
-------------------------------
 1.Primitive Data Type
 2.Reference Data Type

 Data Types
│
├── Primitive Data Types
│   │
│   ├── Numeric Data Types
│   │   ├── byte   (1 byte)
│   │   ├── short  (2 bytes)
│   │   ├── int    (4 bytes)
│   │   ├── long   (8 bytes)
│   │   ├── float  (4 bytes)
│   │   └── double (8 bytes)
│   │
│   └── Non-Numeric Data Types
│       ├── char     (2 bytes)
│       └── boolean  (1 bit*)
│
└── Reference (Non-Primitive) Data Types
    ├── String
    ├── Array
    ├── Class
    ├── Interface
    └── Object

 1.Primitive Data Type

--Primitive data types are the basic built-in data types provided by Java. They store simple values directly.

 2.Reference Data Type

 --A reference data type stores the address (reference) of an object, not the actual data itself.
