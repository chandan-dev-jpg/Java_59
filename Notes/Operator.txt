Relational operator
-------------------

Relational operators are used to compare two values or operands. They always return a boolean result (true or false).



| Operator | Meaning                  | Example    | Result  |
| -------- | ------------------------ | ---------- | ------- |
| `>`      | Greater than             | `10 > 5`   | `true`  |
| `<`      | Less than                | `10 < 5`   | `false` |
| `>=`     | Greater than or equal to | `10 >= 10` | `true`  |
| `<=`     | Less than or equal to    | `10 <= 5`  | `false` |
| `==`     | Double Equal to          | `10 == 10` | `true`  |
| `!=`     | Not equal to             | `10 != 5`  | `true`  |

Logical OR Conditional Operator
-----------------------------

-It is Used to combine or join the multiple into a single statement.
-It is also known as short-Circuit logical operator OR Conditional operator.

In java we have 3 logical Operators.

1) && (Logical AND Operator)
2) LL  (Logical OR Operator)
3) ? : Ternary 

1) && (Logical AND Operator)

The logical AND operator (&&) combines two or more boolean expressions. It returns true only when all conditions are true; otherwise, it returns false. It also uses short-circuit evaluation, meaning the second condition is not checked if the first condition is false.`


2) LL  (Logical OR Operator)

The logical OR operator (||) combines two or more boolean expressions. It returns true if at least one condition is true; otherwise, it returns false. It uses short-circuit evaluation, so if the first condition is true, the second condition is not evaluated.

3) ? : Ternary 

The ternary operator (?:) is a conditional operator that acts as a shorthand for the if-else statement. It evaluates a boolean condition and returns one of two expressions depending on whether the condition is true or false.

Bitwise OR  (|)
---------------

The bitwise OR operator (|) compares each bit of two numbers. If at least one bit is 1, the result is 1; otherwise, the result is 0.


Bitwise AND (&)
-----------------

The bitwise AND operator (&) compares each bit of two numbers. It returns 1 only when both corresponding bits are 1; otherwise, it returns 0.

Bitwise XOR (^)
----------------

The bitwise XOR (^) operator compares each bit of two numbers. It returns 1 if the corresponding bits are different; otherwise, it returns 0.


Bitwise Complement Operator (~) 

The Bitwise Complement operator (~) is a unary operator. It reverses (flips) all the bits of a number.

Left Shift (<<)

The left shift operator shifts the bits of a number to the left by the specified number of positions. Each left shift by one position multiplies the number by 2.

EX:x << n = x × 2ⁿ

Bitwise Right Shift (>>)

The right shift operator shifts the bits of a number to the right by the specified number of positions. For positive numbers, each right shift by one position divides the number by 2.

EX: x >> n = x ÷ 2ⁿ
