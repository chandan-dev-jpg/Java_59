# Java OOP Interview Questions and Answers

### 1. What is OOP?

**OOP (Object-Oriented Programming)** is a programming paradigm that organizes programs using **objects**. Objects contain **data (variables/fields)** and **behavior (methods)**. OOP helps make software reusable, maintainable, secure, and easy to understand.

### 2. What are the Pillars of OOP?

The four pillars of OOP are:

* **Encapsulation** – Wrapping data and methods into a single unit (class).
* **Inheritance** – Acquiring properties and methods from another class.
* **Polymorphism** – One interface, many implementations.
* **Abstraction** – Hiding implementation details and showing only essential features.

### 3. Advantages of OOP

* Code reusability
* Better security through encapsulation
* Easy maintenance
* Easy debugging and testing
* Modular programming
* Supports real-world modeling
* Improves scalability

### 4. What is a Class?

A **class** is a blueprint or template used to create objects. It defines the variables (fields) and methods (behaviors) that objects will have.

**Example:**

```java
class Student {
    String name;
    void study() {
        System.out.println("Studying");
    }
}
```

### 5. What is an Object?

An **object** is an instance of a class. It represents a real-world entity and occupies memory when created.

**Example:**

```java
Student s = new Student();
```

### 6. Difference between a Class and an Object

| Class                                             | Object                      |
| ------------------------------------------------- | --------------------------- |
| Blueprint or template                             | Instance of a class         |
| Does not occupy memory until an object is created | Occupies memory             |
| Logical entity                                    | Physical entity             |
| Created using `class` keyword                     | Created using `new` keyword |

### 7. What is the Instantiation Process?

**Instantiation** is the process of creating an object from a class using the `new` keyword.

**Example:**

```java
Student s = new Student();
```

### 8. What is Default Value? Who provides default value for NSF?

A **default value** is the value automatically assigned to **Non-Static Fields (instance variables)** when no value is assigned by the programmer.

The **JVM (Java Virtual Machine)** provides default values.

| Data Type | Default Value |
| --------- | ------------- |
| byte      | 0             |
| short     | 0             |
| int       | 0             |
| long      | 0L            |
| float     | 0.0f          |
| double    | 0.0           |
| char      | '\u0000'      |
| boolean   | false         |
| Object    | null          |

### 9. What is an Instance Variable (Non-Static Field)?

An **instance variable** (or **Non-Static Field**) is a variable declared inside a class but outside any method or constructor. Every object has its own separate copy.

**Example:**

```java
class Student {
    int age;
}
```

### 10. What is an Instance Method?

An **instance method** is a method declared without the `static` keyword. It can access instance variables and is called using an object.

**Example:**

```java
class Student {
    void display() {
        System.out.println("Hello");
    }
}
```

### 11. What is Variable Shadowing?

**Variable shadowing** occurs when a local variable or parameter has the same name as an instance variable. The local variable hides the instance variable within that scope.

**Example:**

```java
class Student {
    int age;

    void setAge(int age) {
        this.age = age;
    }
}
```

### 12. What is the `this` Keyword in Java?

The **`this`** keyword refers to the current object. It is used to:

* Refer to the current object's instance variables.
* Call instance methods.
* Call another constructor using `this()`.
* Pass the current object as an argument.

### 13. What is the Method Local Search Algorithm?

The **Method Local Search Algorithm** is the order Java follows to search for a variable inside a method:

1. Local variables
2. Parameter variables
3. Instance variables (`this`)
4. Static variables

If the variable is not found, Java generates a compile-time error.

### 14. Difference between Local Variable and Parameter Variable

| Local Variable                    | Parameter Variable                        |
| --------------------------------- | ----------------------------------------- |
| Declared inside a method or block | Declared in the method parameter list     |
| Created when the method executes  | Receives values when the method is called |
| Must be initialized before use    | Gets value from the caller                |
| Scope is limited to the block     | Scope is throughout the method            |

### 15. How Many Types of Variables are there in Java?

Java has **three types of variables**:

1. **Instance Variable (Non-Static Field)** – Belongs to an object.
2. **Static Variable (Class Variable)** – Shared by all objects of the class.
3. **Local Variable** – Declared inside methods, constructors, or blocks.


class Test {

    Test t;
    int val;

    Test(int val) {
        this.val = val;
    }

    public static void main(String[] args) {

        Test t1 = new Test(5);
        Test t2 = new Test(10);

        t1.t = t2;

        t2 = new Test(20);

        System.out.println(t1.t.val);
    }
}
